개요

탈춤을 배우는 동작 인식 게임

웹캠 한 대로 탈춤 동작을 인식·채점하고, 틀린 관절을 짚어 주는 스토리형 탈춤 게임입니다. 전승교육원에 가지 않아도 누구나 탈춤을 배우고 즐길 수 있게 만드는 것이 목표였고, 5명이 함께 만들었습니다.

직접 구현팀원 담당·기존 도구

  1. 결측 관절 보충 모델회전·겹침으로 웹캠이 놓친 관절만 채우는 포즈 모델을 직접 파인튜닝했습니다. 보충 오차(PA-MPJPE)를 164mm에서 97mm로 줄였습니다.
  2. 몸 기준 동작 채점기몸통과 어깨로 사용자 기준 좌표축을 세워, 카메라를 향한 방향이나 체형이 달라도 같은 동작이면 같은 점수가 나오게 했습니다.
  3. 게임 연동몸풀기 캘리브레이션과 본게임 채점을 구현하고, Python 채점과 Unity 연출을 분리했습니다.
  4. 전통 자문봉산탈춤보존회에 직접 연락해 자문을 요청하고 인터뷰를 진행했습니다.

02

문제

웹캠 한 대로 얻은 관절 좌표는 누락과 촬영 조건의 영향을 받아, 그대로 채점에 쓰기 어렵습니다.

관절 좌표를 점수로 바꾸는 과정(결측 보충, 좌표 보정, 채점, 게임 연동)에서 해결해야 할 문제는 세 가지였습니다.

관절 누락

회전, 팔다리 겹침, 화면 밖으로 벗어난 하체에서 관절이 검출되지 않습니다. 탈춤은 회전과 큰 동작이 많아 누락이 잦습니다.

촬영·체형 차이

카메라 기울기, 사용자가 선 방향, 신체 비율이 다르면 같은 동작도 좌표가 달라집니다.

시간 차이

사용자의 반응 지연과 모델 처리 지연이 섞이면, 동작이 맞아도 늦은 것으로 채점됩니다.

03

구현 과정

데이터 증강

탈춤·K-pop·스포츠·일상 동작의 2D·3D 데이터를 함께 사용했습니다. 일부 관절을 의도적으로 가리거나 화면 밖으로 잘라, 실제 촬영에서 발생하는 결측 상황을 학습하도록 구성했습니다.

AI Hub 탈춤 13종목·8방향, 사람 동작 데이터, ASPset-510 활용. 평가 안무 3종과 해당 연희자는 학습에서 제외.

모델 구조

2D 히트맵

현재 화면에서 관절이 위치할 지점을 학습합니다.

3D 위치맵

인체 기준 좌표계에서 관절의 상대적인 위치를 학습합니다.

기존 DINOv2 백본에는 낮은 학습률, 새로 추가한 출력 헤드에는 높은 학습률을 적용했습니다.

결측 관절 보충

연습·본게임 적용

사람 영역을 크롭해 모델에 입력합니다. 다리가 빠지면 예상 다리 길이까지 크롭을 확장합니다.

공통 관절로 좌표를 정합한 뒤 결측 부위만 교체합니다.

공통 관절 4개 이상을 이용한 Umeyama 정합. 관측 좌표와 보충 좌표를 일괄 평균하지 않습니다.

보정·채점

체형·환경 보정

몸통과 어깨축으로 기준축을 잡고, 몸풀기에서 측정한 몸통 길이로 정규화합니다.

관절 각도 8개와 팔다리 방향 벡터 8개를 비교해 부위별 점수로 환산합니다.

반응 지연 보정

몸풀기 단계에서 사용자가 시범 동작을 보고 따라 하기까지 걸리는 반응 지연을 측정합니다. 본게임에서는 정답 동작의 시간축을 이 지연만큼 옮겨 비교해, 동작 정렬 같은 무거운 처리 없이 늦게 따라 한 만큼 감점되는 문제를 보정합니다.

05

결과

3D 위치 오차164 → 97mm
관절 각도 오차22° → 14.4°
관절 누락 비율3.4% → 0.1%
채점 구분 AUC0.702 → 0.750

채점 구분 AUC는 0.05 남짓 올라 수치상으로는 작은 차이로 보입니다. 하지만 실제 플레이에서는 차이가 뚜렷합니다. 관절이 인식되지 않는 비율이 3.4%에서 0.1%로 줄면서, 회전하거나 하체가 화면 밖으로 나가 관절이 자주 사라지던 순간에도 동작을 끝까지 추적해 채점할 수 있게 됐습니다.

보충 전에는 동작을 제대로 해도 관절이 빠진 만큼 감점됐습니다. 보충 모델 적용 후에는 이 감점이 사라져, 같은 동작에는 같은 점수가 나오는 안정적인 채점이 가능해졌습니다.

현장 조사·개선

탈 커스터마이징

부스 설문과 관찰을 바탕으로 얼굴 촬영 자동 확대와 탈 조정 손 커서 개선 의사결정에 참여했습니다.

자리 잡기부터 탈 만들기까지 평균 시간은 1일차 91.7초, 2일차 43.3초로 관측됐습니다.

설문과 가격

팀 설문 173건·게임 137세션. 평균 지불의사 9,052원을 사업화 가격 가정에 활용했습니다.
