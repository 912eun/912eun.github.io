01

개요

근거를 따라갈 수 있는 투자 리포트

국내 반도체 섹터의 공시·리포트·뉴스·주가를 다루는 멀티에이전트 투자 분석 시스템입니다. 파싱 에이전트가 데이터마다 맞는 도구로 정보를 추출해 온톨로지 지식 그래프를 만들고, 낙관(Bull)·비관(Bear) 에이전트가 이 그래프를 근거로 3라운드 토론한 뒤 판정(Judge) 에이전트가 투자 리포트를 작성합니다. 3인 팀 프로젝트입니다.

Bull vs Bear 토론 과정

Bull·Bear 에이전트는 Price DB와 지식 그래프를 조회해 근거를 찾고, 상대의 논리를 반박하는 3라운드 토론을 진행합니다. Judge 에이전트는 토론 이력과 그래프의 인과 경로로 논거 품질과 증거 신뢰도를 검증해 판정합니다.

직접 구현팀원 담당·기존 도구

  1. 파싱 에이전트 고도화공시·주가·뉴스·공급망 등 데이터 소스마다 맞는 파서를 도구로 골라 노드와 관계를 추출하도록 파싱 에이전트를 보완했습니다. 공시·주가 파서를 개선하고 공급망 관계 파서를 새로 만들었습니다.
  2. 지식 그래프 구조·적재기업·이벤트·거시 지표를 나누는 온톨로지 모델과 관계 검증 로직을 만들고, 추출 결과를 Neo4j에 한 번에 적재하는 배치 로더를 구현했습니다.
  3. 주가 표현숫자로 된 주가를 "강한 하락", "약한 상승" 같은 흐름으로 바꾸는 SAX-DM 표현을 붙였습니다.
  4. 토론 근거 연결엔티티 임베딩을 만들어 저장하고, Bull·Bear 에이전트가 그래프와 주가를 토론 근거로 불러오도록 연결했습니다.
02

문제

금융 AI가 투자 판단을 내리려면, 사람이 그 근거를 따라갈 수 있어야 합니다.

금융권

금융권에서는 에이전트형 AI와 리서치 자동화 도입이 빠르게 늘고 있고, 증권사들도 종목 분석과 리서치 초안 작성에 생성형 AI를 쓰기 시작했습니다. 금융위원회의 AI 가이드라인 개정 논의에서도 설명 가능성을 신뢰성 원칙의 하나로 다룹니다. 하지만 LLM에 투자 판단을 그대로 맡기면 어떤 근거로 결론을 냈는지 알 수 없고, 없는 사실을 지어낼 수도 있습니다.

그래서 Bull·Bear 에이전트가 LLM의 내부 지식 대신 온톨로지 지식 그래프에서 토론 근거를 가져오도록 설계했습니다.

03

구현 과정

파싱 에이전트 고도화

파싱 에이전트는 데이터마다 맞는 파서를 도구로 골라 노드와 관계를 추출합니다. 그중 공시·주가 파서를 보완하고 공급망 파서를 새로 추가했습니다.

공시·주가 파서

DART 공시에서 실적·공시 이벤트를 만들고 제목 기반으로 긍정·부정을 분류했습니다. 주가 파서는 ±5% 이상 변동을 주가 변동 이벤트로 생성하고, 주가 데이터의 기업을 리포트에서 추출한 기업 노드와 같은 이름으로 생성해 병합되도록 했습니다.

공급망 파서

리포트 원문에서 기업 간 공급(SUPPLIES)·생산(MANUFACTURES) 관계를 추출하는 파서를 새로 구현해, Agent 계층의 연결을 확보했습니다.

온톨로지 모델과 관계 검증

그래프를 세 계층으로 나누고, 계층 사이에 허용되는 관계를 정의했습니다. 관계마다 정의역·치역 규칙을 두어, 규칙에 맞지 않는 관계는 적재 전에 걸러지도록 했습니다.

LLM이 추출한 영향 관계(AFFECTS)는 관련 시계열과의 피어슨 상관계수로 다시 확인해 신뢰도 점수를 부여했습니다.

관계: AFFECTS, TRIGGERED_BY, SUPPLIES, MANUFACTURES, HAS_SIGNAL, COMPETES_WITH, PARTNERS_WITH, INVESTS_IN.

Neo4j 적재와 시간 연결

적재 흐름
파서 5종리포트 · 뉴스 · 공시 · 거시 · 펀드
병합
정규화엔티티 표준화 · 중복 제거
품질 검사정의역 · 치역
Neo4jAgent·Macro MERGE / Signal CREATE
시간 연결TRIGGERED_BY

노드·관계를 한 건씩 쓰던 방식을 Cypher UNWIND 기반 일괄 적재로 바꿨습니다. Agent 계층은 MERGE로 최신 상태를 유지하고, Signal·MacroMetric 계층은 CREATE로 이벤트 이력을 누적했습니다. 주가 변동과 리포트 이벤트가 같은 기업과 가까운 날짜를 공유하면 TRIGGERED_BY로 연결해, 주가 변동의 원인 후보를 그래프에서 바로 찾을 수 있게 했습니다.

토론 에이전트 입력

주가를 SAX-DM으로 변환해 "약한 상승" 같은 경향 표현을 함께 저장하고, 추출한 엔티티마다 768차원 임베딩을 생성해 그래프에 넣었습니다. 팀원이 구현한 Bull·Bear·Judge 에이전트는 이 그래프와 주가 DB를 근거로 토론합니다.

01

동일 개체의 중복 노드 생성

문제

파싱 에이전트가 같은 의미의 기업·이벤트를 다른 표현의 노드로 적재

원인

LLM 추출 결과의 표기가 문서마다 다르고, 이벤트를 묶을 시간 기준이 부재

해결

엔티티 정규화로 표기를 통일해 불필요한 LLM 호출을 줄이고, 시간 기반 관계와 노드 임베딩·상관관계 검증으로 정량적 연결 경로 구성

결과

주가 변동과 원인 이벤트를 하나의 기업 노드에서 추적

02

수치 시계열에 대한 LLM의 해석 한계

문제

주가를 수치로만 입력하면 추세 해석이 부정확

원인

LLM은 미세한 수치 변화보다 언어로 표현된 경향을 안정적으로 처리

해결

Z-score 정규화 후 이중 평균 기준으로 4단계 기호(강한·약한 상승·하락)로 변환하는 SAX-DM 적용

결과

에이전트가 "완만한 상승 추세"처럼 주가 흐름을 근거로 인용

05

결과

적재와 검증

일괄 적재로 3,000건 이상의 엔티티·관계를 수 초 안에 적재했고, 같은 규모에서 관계의 정의역·치역 검증이 정상 동작함을 확인했습니다. 리포트·주가를 넣은 시험 그래프에서는 768차원 임베딩을 포함한 노드 44개, 관계 21개가 생성됐습니다.

팀 시스템에서의 활용

TSMC 지정학 리스크 질의에서 Bull·Bear 에이전트가 그래프의 연결과 주가 흐름을 근거로 토론했고, Judge가 매수 의견과 리포트를 생성했습니다.
